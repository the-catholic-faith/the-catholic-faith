# The Catholic Faith — starter website

A responsive, traditional Catholic-themed starter website in English, Igbo, and Latin.

## Included
- Responsive homepage and navigation
- Language switcher (English, Igbo, Latin) for the translated interface labels and hero content
- Holy Mass overview with expandable response examples
- Introductory liturgical colour guide
- Links to external Catholic resources for daily readings and official teaching
- Prayers, sacraments, and Catholic teaching sections
- Admin preview with a local-only announcement draft

## Important limitations
- The admin preview is **not secure authentication** and does not publish content online. It saves a draft in the current browser only.
- The daily date is automatic, but daily readings, feast/solemnity, and liturgical colour are **not yet automatically synced** with a local diocesan calendar. Always verify celebrations with the relevant diocese and approved liturgical books.
- Igbo and Latin translations are starter examples and should be reviewed by competent speakers and Catholic liturgical reviewers before public release.
- The website is an independent educational project, not an official Vatican, diocesan, or parish website.
- The Unsplash hero image is remotely hosted. Replace it with a properly licensed/local image if preferred.

## Preview on your computer
Open `index.html` in a modern browser. An internet connection is needed for the remote hero image and external links.

## Publish using GitHub Pages
1. Create or sign in to your own GitHub account.
2. Create a **public repository** named `the-catholic-faith` (or another available name).
3. Upload `index.html`, `styles.css`, `script.js`, and this README to the repository root.
4. In the repository, open **Settings → Pages**.
5. Choose the deployment source (usually deploy from the `main` branch and `/ (root)`), then save.
6. Wait for the published URL shown in Pages settings.
7. To connect a custom domain, first add/verify the domain in GitHub Pages settings, then configure the DNS records at your domain provider as described in GitHub's official guide: https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site/managing-a-custom-domain-for-your-github-pages-site

Do not share your account password with anyone. If you want a genuinely secure admin dashboard where you can edit public content, add a backend/CMS and secure authentication before launch.
